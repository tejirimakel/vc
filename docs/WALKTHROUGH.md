# Walkthrough

This project is a Next.js App Router PWA for TheValueChain news, videos, live stream, and e-copy PDFs.

## Project Map

[Certain] `app/` contains routes and API handlers.

[Certain] `components/` contains shared client components.

[Certain] `lib/` contains shared setup helpers.

[Certain] `public/` contains the service worker, manifest, static images, offline fallback, and copied PDF.js workers.

[Certain] Root config files control Next, TypeScript, ESLint, PostCSS, dependency versions, and middleware.

## Runtime Flow

[Certain] `/` is the public install/landing page.

[Certain] `MobileRedirect` requests a signed PWA access cookie and then sends installed PWA users from `/` to `/mobile`.

[Certain] Middleware protects `/mobile`, `/news`, `/ecopy`, `/video`, `/stream`, and matching content API routes with a signed HttpOnly access cookie.

[Certain] Client pages fetch app API routes such as `/api/news`, `/api/ecopy`, `/api/youtube`, `/api/stream`, and `/api/pdf` after middleware has allowed access.

[Certain] `public/sw.js` adds offline/PWA caching behavior once `components/swRegister.js` registers it.
